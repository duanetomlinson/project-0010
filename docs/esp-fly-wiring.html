Warnings

Power · star at the battery leads (as built)

BAT+ ──┬── Zero 5V pin  ◄── same rail as USB VBUS
       ├── Mod1 VCC          so motors spin on USB alone
       └── Mod2 VCC
BAT− ──┬── Zero GND pin ── sensor GNDs
       ├── Mod1 GND     ── IN2 + IN4 jumpers
       └── Mod2 GND     ── IN2 + IN4 jumpers
Zero 3V3(OUT) ── MPU-6050 VCC + BMP280 VCC only

Motor current never transits the Zero. USB + battery at the same time is unverified — if the S3-Zero has no diode between VBUS and the 5V pin, USB back-feeds the pack.

Before any motor test

  • PROPS OFF. Every run is live — even on USB. Area clear.
  • IN2 + IN4 jumpered to each module's own GND pad (one GPIO per motor, fast decay).
  • Do not drive GPIO5 (EEP) as an output: measured held HIGH externally; drivers are always awake.
  • GPIO6 (ULT) read with the ESP32 internal pull-up; LOW = fault.
  • Sensors on 3V3(OUT) only, never on 5V or battery.
  • No continuity BAT+ to BAT− after all joints; JST polarity metered.
  • One power source at a time (USB or battery / boost).

Test order

  1. USB only → import step2_scan → expect [104, 118] (0x68, 0x76).
  2. USB only, props off → import step6_motors → each corner solo, then all four; watch nFAULT.
  3. Confirm spin by eye: FR + RL = CCW, RR + FL = CW.
  4. ESP-Drone build: pins in espdrone-overrides.sdkconfig match this page (MOTOR01=1, 02=2, 03=4, 04=3, SDA=10, SCL=9, MPU INT=7).
